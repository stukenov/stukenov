## Hi, I'm Saken

I build **systems software, AI for low-resource languages, and developer tools** — from a memory-safe AV2 video decoder in Rust to small language models for Kazakh trained from scratch.

Based in Kazakhstan. Building [Adapto](https://adapto.kz) — an AI layer for businesses.

### What I work on

**🦀 Systems & Rust** — [rav2d](https://github.com/stukenov/rav2d) (AV2 decoder), [pigeon](https://github.com/stukenov/pigeon) (Telegram-compatible server), [adapto-core](https://github.com/stukenov/adapto-core) (a Rust web framework with an embedded document DB) and its [VS Code extension](https://github.com/stukenov/adapto-vscode).

**🇰🇿 Kazakh-language AI** — an open stack for an underserved language: [slm](https://github.com/stukenov/slm) (small LMs, 14M–600M params, from scratch), [turkic-tts](https://github.com/stukenov/turkic-tts) (text-to-speech), [kazakh-speech-pipeline](https://github.com/stukenov/kazakh-speech-pipeline) (Whisper + GPT-4 ASR), [qazlang](https://github.com/stukenov/qazlang), and the [kazakh-nlp-toolkit](https://github.com/stukenov/kazakh-nlp-toolkit) umbrella.

**🤖 AI tooling** — [omniff](https://github.com/stukenov/omniff), [data-translate](https://github.com/stukenov/data-translate) (translate entire HuggingFace datasets in one command), and AI dubbing pipelines ([kazakh-video-dubbing](https://github.com/stukenov/kazakh-video-dubbing)).

**📺 Broadcast & streaming** — playout servers, HLS/RTMP/WebRTC pipelines, FAST channels, VOD platforms: [fast-tv-playout-core](https://github.com/stukenov/fast-tv-playout-core) (Go), [live-streaming-server](https://github.com/stukenov/live-streaming-server) (NestJS/MediaMTX), [tv-playout-backend](https://github.com/stukenov/tv-playout-backend) + [frontend](https://github.com/stukenov/tv-playout-frontend).

**🛠 Developer tools** — [keste](https://github.com/stukenov/keste), [postpilot](https://github.com/stukenov/postpilot), [erp-dsl-generator](https://github.com/stukenov/erp-dsl-generator) (define your domain once, generate full-stack code).
